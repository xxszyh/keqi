# 电脑版与手机局域网同步

0.11.0 开发版面向 Windows x64、Android 8.0 及以上。手机继续独立读取平台和安排通知；电脑退出、休眠或关机时，两端各自保存修改，待电脑运行且同一局域网可互通时交换。

## 安装与配对

1. 安装电脑版，或解压便携目录后打开 `Keqi.exe`。便携目录需要完整保留，不能只复制 EXE；内含 Java 运行环境。
2. 在手机覆盖安装同签名的 0.11.0 APK。保留旧数据库、课程选择和通知回执，不需要卸载。
3. 电脑进入「设置 → 手机与电脑」。有多个网卡时，选择手机所在 Wi-Fi/以太网对应地址，点「使用此网络」。不要选择 VPN 或无法互访的虚拟网络。
4. 点「连接手机」，手机在同一页面点「扫描电脑二维码」。首次才请求相机权限；也可复制完整文字配对信息到手机。
5. 在电脑的「配对申请」中确认手机。二维码有效 5 分钟，手机等待确认约 90 秒；失效后重新生成。确认前不能读取任务。

首次配对会把手机已有的、能够确认来源身份的任务和人工修改合并到电脑。平台 Cookie、密码、验证码和登录会话不会同步。学习通和 MOOC 要在两端分别完成官方登录。

Windows 提示防火墙权限时，只为需要的可信私人网络允许课期附带的 Java 进程。不需要关闭防火墙。校园网/访客网可能禁止设备互访，即使 Wi-Fi 名称相同也无法连接；可换普通路由器或能互访的热点。无线发现不可用时，可在手机手动更新电脑的 IPv4 和端口，证书身份仍会核对。

## 日常操作

- **手动待办**：点「新建待办」，标题必填，课程和截止可留空；可加优先级、标签、备注及重复规则。无截止的个人事务不会算成逾期或截止未知。
- **任务详情**：编辑记录、人工已处理、补充截止、稍后提醒；可添加、改名、排序或移除子任务。人工操作不会提交到平台。
- **重复任务**：每日/每周/每月、间隔、指定星期、结束日期和月末处理；每次独立状态。编辑一个实例的截止不改变下一次；修改后续规则、暂停或结束系列在详情中操作。
- **批量操作**：开启多选，修改处理状态、优先级、标签或稍后提醒；只能将手动待办放入回收站。回收站可恢复。
- **课程管理**：启用、移出和恢复在两端共享。普通搜索、临时筛选、深色模式、免打扰和通知回执分别保留在本机。
- **冲突**：同一字段离线修改出现不同内容时，详情保留多个版本。先核对内容再选择版本；备注不会被最后一次上传静默覆盖。平台状态/截止不一致时提示重新读取核实。
- **桌面托盘**：关闭窗口后继续运行；托盘菜单可打开、刷新或完全退出。通知依赖 Windows 通知设置。`Ctrl+N` 新建，`Ctrl+F` 搜索。

手机前台通常每 30 秒尝试交换；后台合并到原有 JobScheduler，默认约 30 分钟，系统可能延迟。网络失败逐步延长重试间隔；需要重新配对/处理协议问题时可点「立即同步」重新核对。电脑数据变化通常在下次手机交换后出现。

## 备份与边界

电脑可导出/合并恢复任务备份；不含平台会话、设备授权令牌或 TLS 私钥，恢复不会覆盖当前设备身份。恢复的不同字段版本仍保留候选。备份是私有数据，请自行保管。

首版一台电脑管理一个工作区，使用局域网 IPv4。解除关联和电脑解绑均保留各端缓存；解除关联后不能直接把另一个电脑工作区的内容混进当前工作区。主机重装后从旧备份重建同步日志、跨工作区换机、IPv6、多主机与跨网同步尚未提供完整迁移流程。身份或 epoch 不一致时停止交换并保留未上传修改。
