# 使用说明

## 安装

从 [GitHub Releases](https://github.com/xxszyh/keqi/releases/latest) 下载 APK。支持 Android 8.0 及以上，需要可正常更新的 Android System WebView。同一官方签名的更新可直接覆盖安装；卸载会删除本机数据。

在「设置 → 通知与后台」允许 App 通知，并发送测试通知。按手机系统设置允许自启动及后台运行，调整电池限制。电脑关机不影响手机；手机需要开机并联网才能发现新任务，缓存截止可离线提醒。

## 连接平台

在「设置 → 课程平台」选择学习通或中国大学 MOOC，进入官方页面完成登录，再点上方「完成连接」。课期不读取或保存密码输入。课程目录自动读取，随后同步作业、测验、考试和互评。

登录页面空白时可重开，必要时重置该平台登录会话或切换电脑版登录。需要人工验证时，从平台详情打开验证页面，按官方提示处理后返回刷新。更换账号前先断开该平台；断开会清除本机该平台任务、课程配置和会话，不影响另一个平台。

## 课程与筛选

待办顶部课程按钮打开可搜索的单门课程筛选；底部「管理保留课程」进入批量管理。设置里的课程管理提供相同入口。

- 取消勾选：任务不显示也不提醒，课程仍保留在管理列表，重新勾选恢复。
- 移出：从普通课程、任务、统计、日历和提醒中排除，同账号同步/重新登录保持排除；不是在平台退课。
- 恢复：保存后可立即撤销，或在「设置 → 课程管理 → 重新导入」恢复；本机保留历史任务与人工修改，刷新获取更新。

管理默认按平台收起，修改后统一保存，关闭取消草稿。按平台批量操作不影响另一个平台。

顶部切换全部/作业/测验/考试。「筛选」选择平台、完成状态和日期范围，应用后生效。日期分组可收起；历史、远期和日期未知默认收起，搜索会展开匹配项。

## 日期、完成与提醒

任务圆圈与详情里的人工处理只修改本机状态，不会向平台提交。详情可以补充截止和稍后提醒；提交与互评分开。提醒与免打扰默认提前 3 天、1 天、3 小时，可选择预设或自定义小时。

平台只提供考试开始时间时不把它当成截止。月日没有年份时等待确认：同一学期可在学习通详情填作答起始年份，跨学期课程在任务详情逐项补充日期。

同步摘要点击可查看本轮数量、错误、上次尝试与完整同步；已缓存旧任务不代表本轮读取成功。详情失败保留旧截止并标明沿用。

## 适用范围

目前读取可识别的学习通课程作业与已发布考试，以及中国大学 MOOC/SPOC 数据中的作业、测验、考试和互评。列表之外、班群公告、学校单独考试系统不保证覆盖。请对照官方平台抽查数量、状态和日期。

后台由 JobScheduler 和非精确 AlarmManager 调度，省电、断网、休眠、通知权限关闭或强行停止会延迟/停止提醒，不能保证固定时刻送达。强行停止后需重新打开 App。

用户反馈请使用 [Issues](https://github.com/xxszyh/keqi/issues)，提供版本、手机/WebView 版本和脱敏步骤，不发布账号、Cookie、学校身份和完整登录链接。
