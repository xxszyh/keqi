# 课期 0.8.0

新增学习通考试卡片与考试安排表读取。根据课程和班级身份关联课程名字，考试与作业共用课程勾选，进入待办、截止日历和提醒，支持「类型 → 考试」筛选。无法唯一关联课程的考试进入可选的「其他考试（未关联课程）」；缺少稳定考试编号的记录会提示未纳入提醒。读取任务只访问列表，不打开开始考试、领取试卷或作答页面。

修正已复现的课程页面跳转识别过严问题：允许已知只读入口跳转到官方课程视图，在当前账号与有效入口字段的条件下接受内容；开始考试、提交及非平台 URL 仍不能成为同步入口。这个回归使用代表性页面，尚未取得用户手机的最终响应地址，不能据此认定已确认截图全部失败原因。

同步消息分开说明本轮读到的作业、考试与本轮未更新的旧记录；作业列表成功、详情失败时明确说明并保留旧截止。上一轮缓存不再暗示本轮全部读取成功，上次尝试与上次完整同步分别显示。考试结束与已作答分开判定，只有开考时间不推断截止，没有年份也不自动猜。

验证通过：27 项受保护页面续读、25 项考试解析/身份/选择/生产部分同步、17 项浏览器 HTTP 202 页面渲染、19 项考试界面/日历/原生操作检查；47 项领域、107 项连接/课程、19 项基本界面、16 项隐藏、18 项独立课程选择和 11 项名称显示检查。APK v2/v3 签名有效，使用与 0.7.0 相同签名，可覆盖安装。

范围为官方列表提供并能识别的考试。真实手机的考试覆盖、字段、锁屏通知和后台持续运行仍需核对；学校定制或独立考试系统不保证覆盖。

结构依据：考试安排表只读入口和表格见固定版本 [Xuexitong-mcp 客户端](https://github.com/DanMo661/Xuexitong-mcp/blob/ebce2cc735bc7acc45fac7ccf32bcefe1a6b2a54/xuexitong_mcp/client.py)；移动考试卡片及表格的 HTML 字段由发布者的[列表脚本源码](https://sleazyfork.org/en/scripts/579565-%E5%AD%A6%E4%B9%A0%E9%80%9A%E4%BD%9C%E4%B8%9A-%E8%80%83%E8%AF%95-%E4%BB%BB%E5%88%97%E8%A1%A8-cc%E4%BC%98%E5%8C%96%E7%89%88/code)核对，仅参考页面字段，解析与同步代码在本项目实现。
