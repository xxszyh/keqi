# 课期 0.6.0

学习通课程选择不再显示「课程 + 编码」。新版读取封面旁的课程名字、名称元素完整 title、隐藏字段卡片的名称，并允许同一课程的后续链接补齐名字。名称缺失时显示「课程名称待更新」，明确提示刷新；不借用其他课程的名字。

刷新后，课程选择、筛选、作业列表、详情和提醒使用课程名字。已存课程和历史作业会补齐名字；原勾选状态、截止日期、人工修改、作业身份与提醒版本保留。暂时未读到的名字不会覆盖已读到的名字。

直接覆盖安装「课期-安卓-v0.6.0.apk」，打开课期后点右上角 ↻ 刷新，不必先断开学习通。

通过 106 项连接/课程、47 项领域、7 项浏览器 DOM 联检、19 项界面、16 项课程隐藏、18 项平台选择和 11 项旧名称更新检查。名称解析、旧名称覆盖、界面编码回归均先失败后通过。APK 编译、签名和包校验通过。用户已提供 32 门课程选择截图，真实手机名称仍需核对；网页联检使用测试样例。
