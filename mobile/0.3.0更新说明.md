# 0.3.0 更新

作业页新增「选择课程」，设置页也可调整。取消勾选后，各状态列表（包括全部和已完成）、日历、统计及提醒均忽略该课程；数据与人工标记继续保留。重新勾选恢复。批量选择一次 SQLite 事务保存并重建提醒；同步及重新连接共用 `CourseSelection.merge`，刷新课程信息时继承已有选择。原有课程字段可直接沿用，覆盖升级不需要迁移数据库。

旧版界面在待办中使用课程开关，但「全部」和「已完成」绕过了这一过滤。新代码统一从所选课程生成列表，课程筛选项同步更新，隐藏当前筛选课程时退回所有已选课程。回归脚本先出现 FAIL，再通过修正后的 16 项检查。

学习通的新录屏显示空白和「平台请求了其他页面」；用户说明首次能打开内容，第二次进入空白。新版直接打开 [官方手机登录入口](https://passport2.chaoxing.com/mlogin)，不再依赖首页中转；登录浏览器允许正常 HTTPS 网页跳转，区分内嵌页面与主页面，不再把内嵌空白页当作未知主页面。提供重新打开登录页及官方电脑登录入口。「重置登录」复用按平台清理会话的方法，只清理学习通的会话备份、可识别 Cookie 和网页存储，保留课期内的课程、作业和课程选择；已连接平台改为需要重新登录，不删除历史作业。受阻时显示协议类型和域名，验证请求失败显示错误类型，查询参数不写入提示。

登录 WebView 没有原生 JavascriptInterface，保留浏览器本身的 Cookie 域隔离及证书校验；原生连接验证、会话保存和采集仍限定官方平台请求。浏览器兼容性改动不会把访问其他身份页面当成连接成功，仍须平台返回可验证的账号身份。内嵌导航的处理参考 [Android WebViewClient](https://developer.android.com/reference/android/webkit/WebViewClient#shouldOverrideUrlLoading(android.webkit.WebView,%20android.webkit.WebResourceRequest)) 的主页面标识规则。

公开页面联检调用实际 Java 路由，在同一 Cookie 环境中两次打开手机登录页，再打开电脑登录页，均能显示手机号和验证码输入，无被阻止导航或页面脚本错误。它不包含账号验证或真实验证码登录。录屏没有具体受阻 URL，公开匿名环境也没有复现用户登录后的跳转，所以学习通实机登录问题是否消失仍需验证，不把类别回归或桌面浏览器检查当作完整根因证明。

用户已确认 0.2.0 的 MOOC 可连接；本版覆盖升级保留该连接，MOOC 的个人课程接口继续沿用。完整验证范围见「验证记录.md」。
