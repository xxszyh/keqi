# 课期 0.9.0 · 列表界面

首页改为白底任务列表，按已逾期、今天、明天、7 天内、之后和日期待确认分组。任务名称、课程、平台、类型和截止时间集中显示，去掉首页大统计卡片与逐项任务的圆角容器。

- 顶部可直接切换全部、作业、测验、考试；搜索从放大镜展开，状态、平台、课程和时间范围筛选保留在「筛选」。
- 课程选择增加搜索，原有两个平台独立选择、全选和全部隐藏继续保留；勾选同时控制列表、日历、统计和提醒。
- 同步问题显示简短摘要，点击查看完整平台消息、上次尝试和上次完整同步。设置页也可查看同步详情。沿用旧截止逐项提示；人工补充时间不会误标为旧平台截止。
- 圆圈可以标记本地已处理，操作前确认；平台完成与人工处理分别显示，不会提交作业或考试。
- 日历与设置使用同一套文字、分隔线和 SVG 图标。设置增加持久保存的深色模式，并调整主界面的系统栏颜色。

不更改课程读取、账号会话、考试解析或提醒规则。安装包与 0.8.0 使用同一签名，支持直接覆盖升级并保留本地数据。

设计观察来自 [Tasks](https://github.com/tasks/tasks)、[Fossify Calendar](https://github.com/FossifyOrg/Calendar) 与 [Ant Design Mobile](https://github.com/ant-design/ant-design-mobile)。未引入这些项目的代码、依赖或品牌资产。

验证包括现有界面与课程选择检查、新版日期分组、搜索、摘要详情、人工处理、主题与原生接口、320/390/780 像素布局，及 APK 构建、签名、对齐和打包内容。尚未在 iQOO 手机实测此次界面。
