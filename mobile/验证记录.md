原 0.2.0 连接判定的快速检查先输出了两项 FAIL：已验证的 MOOC 会话因学习链接数量为零被拒绝；普通学习通 Cookie 被误认为连接成功。修正后的同一检查继续 PASS。新增的学校回跳修复也不能代替真实短信登录、账号登录和课程采集验证。

本机匿名请求官方课程入口得到 302 到官方登录页；学校 HTTP 入口返回本机网络的 403，HTTPS 入口证书域名不匹配，未绕过网络或 TLS 校验。尝试用 GUI 工具查看用户 Edge 的已登录页面时，工具因无法可靠确定当前浏览器 URL 而停止，未取得该页面作为服务器账号及学校字段解析的验证样本。账号/学校字段的新增检查使用明确的测试数据。

APK 编译和包结构校验不能证明所有学校页面均兼容，浏览器界面检查也不能代替 Android WebView、JobScheduler 或 AlarmManager 的实机检查。

0.5.0 的最小回归在旧生产判定输出 FAIL：有效账号 Cookie 和可解析的课程卡片，因页面没有旧学校/账号声明而被拒绝。旧 UID 别名先于 _uid 时的有效账号也先出现 FAIL。原平台卡片没有学习通独立选择按钮，界面回归先出现 AssertionError。修正后的同一回归全部通过；课程页验证与解析共享实现。

## 0.6.0 课程名称回归

新增的生产解析回归先失败：课程封面和名字分开放置时，解析返回「课程 255733792」，没有返回样例中的「形势与政策3」。修正为在同一选课记录的卡片范围内查找名称；封面先出现也允许后续名字补齐，不能借用别的课程名字。新增名称跟随链接、camelCase 名称、隐藏字段、多个链接、封面类名和跨课程隔离检查，共 7 项生产解析检查；缺少名称显示待更新并提示。

课程合并回归也先失败：暂时缺失的名称覆盖已读到的名字。修正后保留旧的真实名字与 enabled 选择。生产 Store.ingest 使用 refreshTaskTitles 更新历史作业的课程名，包括本轮不采集的隐藏课程；不改作业标识、提醒版本、截止日期或人工修改。增加 4 项领域检查，总计 47 项。

新 course_name_test.py 在旧界面先失败：课程选择仍出现 255733792。修复后 11 项检查通过，覆盖旧编码的显示、刷新成真实名字、勾选保持、筛选选项、作业列表及详情。原有 19 项界面、16 项课程隐藏、18 项平台独立选择检查继续通过；DOM 提取到生产认证方法的 7 项联检扩展为 5 种卡片格式，继续通过。

以上使用明确的网页样例和旧数据回放，没有取得用户真实网页 HTML，不能等同于手机实际 32 门课程名称已经核对。用户截图仅确认课程数量和选择界面。新 APK 同一签名覆盖安装，刷新会重新读取名称；不要求删除课程或断开已有连接。


## 0.7.0 HTTP 202 与详情就绪回归

用户最新截图显示真实课程名称、已有作业，以及「金工实习」「概率论与数理统计」等课程的 HTTP 202 错误。生产 Http.responseError(202, "chaoxing") 的回归先出现 AssertionError：返回通用平台请求失败，而没有提供网页续读。修正为明确的 BrowserRequired，再由课程读取模块继续加载。连接/课程检查共 107 项，其中 4 项为此前取得的真实匿名响应检查。

新增 chaoxing_read_test.py 的 26 项检查覆盖生产状态分类到续读方法、课程入口/列表/详情到实际解析器、普通成功页不重复开浏览器、200 加载页、202 未就绪不能作零作业、真正空列表、登录失效、权限受限、账号冲突、人工验证和受保护框架范围。详情只有静态「作业详情」标题但数据未加载的检查也先失败；修正后需要实际日期/题量元数据才交给解析器。

新增 chaoxing_202_browser_test.py 的 14 项检查使用明确的 HTTP 202 网页样例，正常浏览器执行网页跳转和动态内容加载，调用生产快照提取与 Java 门控/解析方法，验证实际作业标题和截止。覆盖同源嵌入详情、未就绪页面、账号冲突和「打开验证页面」的原生动作消息。没有模拟或自动完成滑块、验证码；出现人工验证交由用户在平台页面完成。

同步中复用一个 WebView；每页最多约 28 次轮询、35 秒等待，未就绪时仅在两处重载，网页续读累计预算 90 秒。未知的受信任 HTTPS 中间页可以正常导航，但只在支持的受保护课程/作业页就绪后读取数据。同源框架只读取浏览器允许访问的 DOM，跨源的受保护作业框架可按网页已有地址直接打开，最多跟随三个框架地址。Cookie 始终按响应地址获取，并核对已验证的账号；使用保存的登录浏览器 User-Agent，不关闭 TLS 验证、不允许明文平台请求、不向不相关域名传送 Cookie。验证入口的元数据更新使用事务，保护并发的课程勾选。

47 项领域、19 项界面、16 项隐藏过滤、18 项独立选择及 11 项名称显示检查继续通过。未就绪或验证失败的详情保留旧截止和旧作业，不能宣称全量同步成功。原始资料是用户截图，没有手机请求正文；本机两个不带账号参数的公开入口仅返回 302，因此没有证实服务器侧的 202 是否来自网页验证、等待处理或其他原因。真实手机续读、作业范围和字段仍需核对。

APK 0.7.0 / versionCode 7 与 0.6.0 使用同一签名，可覆盖安装；包校验与 SHA-256 见 build-info.json 和 build/release-check.json。
