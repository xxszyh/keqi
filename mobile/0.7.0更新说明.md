# 课期 0.7.0

截图中的 HTTP 202 不再直接终止课程读取。新版在课程入口、作业列表和详情使用已保存会话的普通 WebView 继续加载，沿用登录浏览器 User-Agent，只在实际内容就绪后交给解析器。覆盖动态内容和受保护的嵌入详情。

等待与重载有上限。未就绪时保留已有课程、选择、作业、截止和人工修改，并显示部分同步。平台要求人工处理时，在学习通设置卡片点「打开验证页面」，完成平台提示，返回后刷新。无需先断开连接。

直接覆盖安装「课期-安卓-v0.7.0.apk」，点右上角 ↻ 刷新。原有课程名称和选择功能保留。

通过 107 项连接/课程、26 项网页续读策略、14 项实际 HTTP 202 网页样例渲染、47 项领域、19 项界面、16 项隐藏过滤、18 项独立选择和 11 项名称显示检查，以及 APK 编译和签名检查。202 的通用失败和详情占位页回归先失败、修正后通过。网页样例不是用户实际会话；真实手机上的续读仍需验证。

HTTP 202 表示请求已接受、处理可能尚未完成，不能直接认定为业务数据已就绪：[RFC 9110 §15.3.3](https://www.rfc-editor.org/rfc/rfc9110.html#section-15.3.3)。没有获得手机的响应正文，不能断定平台为何返回 202；本次修正的是已确定的客户端续读缺口。
