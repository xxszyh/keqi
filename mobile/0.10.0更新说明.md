# 课期 0.10.0 · 课程管理与筛选

课程很多时，设置页和选择面板不再直接铺开全部课程。待办的单门课程筛选和批量课程管理使用独立的底部面板，保留白底、细分隔线和绿色操作按钮。

- **课程收起与移出**：管理列表按平台默认收起，可搜索完整课程名。取消勾选隐藏任务并关闭提醒，课程仍保留在管理列表；「移出」则从普通课程列表、任务、统计、日历和提醒中排除，后续同步及同账号重新登录保持排除。移出前确认，保存后可撤销，也可在「设置 → 课程管理 → 重新导入」恢复。
- **待办课程选择**：可搜索的底部面板替代系统下拉菜单，完整显示课程名称与当前选择。面板底部有课程管理入口，批量管理支持按平台操作、取消草稿和统一保存。
- **筛选**：平台、完成状态和截止范围集中在底部面板，修改后应用；取消不改变当前结果。任务类型继续使用顶部标签，筛选里不再重复。首页分别显示保留课程总体待办和本次筛选数量。
- **任务分组**：各日期组可展开、收起；远期、历史和日期待确认默认收起，搜索时自动展开匹配记录，避免未确认日期的任务占满页面。
- **设置**：首页缩成课程平台、课程管理、提醒与免打扰、通知与后台、外观、关于六个入口。平台登录、验证和账号操作放入详情；课程管理摘要按平台收起。
- **提醒与操作**：提醒时间使用天/小时选项并支持自定义小时；免打扰与深色模式使用开关。通知已开启时显示「管理通知权限」。返回键优先关闭面板或返回设置首页。

移出是本地排除操作，不会在学习通或 MOOC 退课。为支持撤销和重新导入，本机保留被排除课程的历史任务及人工修改，普通页面不展示。移出后的新任务不再写入；恢复后刷新获取更新。

安装包与 0.9.0 使用相同签名，可直接覆盖安装，保留连接、课程选择、历史任务和人工日期。
